Zakuroishi: 3DS emulator for Android handhelds

An experimental Nintendo 3DS emulator for Android, built for dual-screen handhelds such as the AYN Thor. Games run as ahead-of-time recompiled native ARM64 code, with a Vulkan renderer, HD texture packs, frame generation and each screen on its own display. Nothing is decompiled: each game's code is recompiled once on a PC with 3dsrecomp.

Requirements

  • 64-bit ARM Android 11 or newer with Vulkan 1.3.
  • A legally obtained, decrypted 3DS game.
  • Native game code built on a computer (Rust and the Android NDK). The app does not compile games on your handheld. See the native library guide.
  • HD texture packs are optional.

Developer preview, tested on one device (an AYN Thor), mostly with one game (Pokémon Ultra Moon). See known issues. The app includes no games, firmware, keys or texture packs.
